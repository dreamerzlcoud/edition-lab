# Edition Lab

[Open the live app](https://dreamerzlcoud.github.io/edition-lab/). Rotate a sneaker, compare two weekly forecasts, and make a stock decision using real U.S. StockX resale records.

미국 스니커즈 리셀 거래 기록으로 일주일 뒤의 거래 건수를 예측하고, 그 주에 몇 켤레를 준비했을 때 얼마나 남았을지 실험하는 웹앱입니다. ZIP을 풀고 `dist/index.html`을 브라우저에서 열면 실행됩니다. 예측과 시뮬레이션은 모두 브라우저 안에서 계산합니다.

## 앱 사용법

1. 첫 화면의 신발을 좌우로 드래그해 각도를 바꿀 수 있습니다.
2. **Weekly forecast**에서 컬렉션을 선택합니다. **Sales**는 실제 거래 건수와 예측을, **Forecast error**는 각 모델이 몇 건 높거나 낮게 예측했는지를 보여줍니다. 그래프 위에서 주를 선택하거나 아래 표를 열어 수치를 확인하세요.
3. **The stock game**에서는 그 주를 예측한 두 모델의 수치만 보고 준비할 켤레 수를 입력합니다. **Reveal sales**를 누르면 실제 표본 거래와 비교해 남거나 부족한 수량을 확인할 수 있습니다. 게임의 33개 주는 차트에서 평가한 마지막 12주보다 앞선 기간입니다.
4. **Explore the inventory simulator**를 열면 실제 거래 건수를 보면서 시작 재고를 조절할 수 있습니다. **Data & method**에는 원자료와 주별 집계 CSV가 있습니다.

## 거래 데이터

StockX는 2017년 9월 1일~2019년 2월 13일 미국 구매자에게 배송된 두 컬렉션의 거래 중, 각 색상·일자 조합에서 일정 비율을 무작위 추출했습니다. 정확한 추출 비율은 공개되지 않았습니다. 원본 엑셀 파일은 출처에서 직접 내려받을 수 있습니다. 이 프로젝트에는 원본에서 계산한 주별 거래 건수가 들어 있습니다. StockX의 공지에는 원본을 퍼블릭 도메인으로 배포한다는 명시가 없습니다. [공식 데이터 설명](https://stockx.com/news/the-2019-data-contest/) · [원본 엑셀](https://s3.amazonaws.com/stockx-sneaker-analysis/wp-content/uploads/2019/02/StockX-Data-Contest-2019-3.xlsx)

| 구분 | 전체 | Yeezy 350 | Off-White × Nike |
|---|---:|---:|---:|
| 원본 거래 건수 | 99,956 | 72,162 | 27,794 |
| 전체 7일이 포함된 75주의 거래 건수 | 98,705 | 71,437 | 27,268 |

엑셀의 `Raw Data` 시트에서 한 행을 거래 한 건으로 세었습니다. `Order Date`를 기준으로 월요일부터 일요일까지 합산했습니다. 시작과 끝에 일부 날짜만 관측된 두 주에서 각각 54건과 1,197건을 제외했습니다. 최종 분석 기간은 2017년 9월 4일~2019년 2월 10일입니다. CSV의 `week_start`는 각 주의 월요일, `all`·`yeezy`·`offwhite`는 표본 거래 건수입니다.

## 예측 검증 결과

첫 63주의 기록을 확보한 뒤, 마지막 12주(2018년 11월 19일~2019년 2월 10일)를 한 주씩 예측했습니다. 기준 모델은 직전 4주의 평균을 사용합니다. 선형 회귀는 절편, 직전 주의 거래 건수, 직전 4주의 평균을 사용하며 음수 예측은 0으로 조정합니다. 매주 예측을 먼저 기록한 후 해당 주의 실제 거래를 학습 이력에 추가합니다.

| 컬렉션 | 4주 평균 모델 MAE | 선형 회귀 모델 MAE |
|---|---:|---:|
| 두 컬렉션 합계 | 849.48 | 701.40 |
| Yeezy 350 | 670.08 | 548.06 |
| Off-White × Nike | 323.94 | 274.13 |

MAE는 예측과 실제 거래 건수 차이의 절댓값을 12주에 걸쳐 평균 낸 수치입니다. 각 모델의 반올림 전 예측으로 계산했습니다. 이 기간에 두 컬렉션을 합산한 회귀 예측은 실제 주별 거래 건수와 평균 약 701건 차이가 났습니다.

## 재고 실험의 의미

시작 재고와 그 주의 관측 거래 건수 중 더 작은 값만큼 판매된다고 가정합니다. 예를 들어 표본 거래가 100건이면 시작 재고 120켤레에서는 20켤레가 남고, 80켤레에서는 관측 거래보다 20켤레 부족합니다. 실험에서는 한 건당 한 켤레로 환산하며, 선택한 컬렉션 안에서 사이즈와 색상을 구분하지 않습니다. 해당 주에 재입고가 없고 다음 주로 재고를 넘기지 않는다고 가정합니다.

실제 재고, 품절 시점, 구매를 포기한 사람, 브랜드 생산량은 기록에 없습니다. 중고거래에는 이전에 생산한 신발도 등장할 수 있습니다. 따라서 낮은 거래 건수에는 약한 수요와 부족한 공급이 모두 영향을 줄 수 있고, 이 실험을 실제 생산량으로 환산하려면 추가 데이터가 필요합니다.

## 직접 재현하기

필요한 도구는 Python 3.10 이상과 Node.js입니다. 웹앱을 열어 결과만 확인할 때는 둘 다 설치할 필요가 없습니다. 아래 명령은 압축을 푼 프로젝트 폴더에서 실행합니다.

1. 위 원본 엑셀을 다운로드하여 프로젝트 폴더에 `stockx.xlsx`로 저장합니다. 사용한 파일의 SHA-256은 `cd339458a1c8b066a2697779d3096a04f5632a18de7a4a1940c0f605ecc24c28`입니다.
2. 브라우저용 데이터와 CSV를 다시 생성합니다.

   ```sh
   python -B tools/build_data.py stockx.xlsx
   ```

   `dist/weekly.js`에 75주의 집계와 메타데이터가, `dist/weekly-counts.csv`에 주별 거래 건수가 기록됩니다. 순수 JSON 파일이 필요하면 다음 명령을 실행합니다.

   ```sh
   python tools/aggregate.py stockx.xlsx weekly.json
   ```

3. 웹앱과 동일한 모델 코드로 검증 결과를 다시 계산합니다.

   ```sh
   node tools/scores.cjs
   ```

   출력에는 모델별 평균절대오차(MAE), 평균제곱오차의 제곱근(RMSE), 절대오차 합을 실제 거래 수 합으로 나눈 백분율(WAPE)이 포함됩니다.

4. `dist/index.html`을 열어 결과를 확인합니다. 로컬 웹 서버가 필요하면 다음 명령을 실행한 뒤 브라우저에서 `http://127.0.0.1:8000/`을 엽니다.

   ```sh
   python -m http.server 8000 --bind 127.0.0.1 --directory dist
   ```
